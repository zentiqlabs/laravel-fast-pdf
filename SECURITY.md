# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within `zentiq-labs/laravel-fast-pdf`, please do not open a public issue. Instead, send an email to support@zentiqlabs.com.

All security vulnerabilities will be promptly addressed, and we will issue a patch release as soon as possible.
